# 🏁 Datamaq Costs Plugin

Sistema avanzado de gestión de costos críticos y presupuestación automatizada para servicios de ingeniería.

## Descripción
Este plugin integra la Google Maps Distance Matrix API con WooCommerce para permitir la venta de relevamientos técnicos con precios dinámicos basados en la distancia real desde la planta de Datamaq.

## Stack Técnico
- **Arquitectura**: Clean Architecture (Domain Driven Design).
- **Backend**: PHP 8.1 / WordPress Hooks.
- **Frontend**: Vanilla JS (jQuery-based) + CSS3.
- **APIs**: Google Maps (Distance Matrix, Places).

## Estructura de Documentación
Los detalles del proyecto se encuentran en la carpeta `docs/`:
- `SRS.md`: Requerimientos y reglas de negocio.
- `TODO.md`: Roadmap y tareas pendientes.
- `DISCOVERY.md`: Dudas y definiciones en curso.

## Configuración
1. Activar el plugin.
2. Ir a **Ajustes > Datamaq Costs**.
3. Activar el **Modo Edición**.
4. Cargar la API Key de Google Maps y las tarifas base.
